# Веб-ресурс «Защити свой аккаунт»

Учебный веб-ресурс, содержащий практические рекомендации по обеспечению безопасности учётных записей в социальных сетях. Проект разработан для того, чтобы помочь пользователям разобраться в базовых принципах информационной безопасности, пошагово настроить приватность в популярных социальных платформах и проверить полученные знания с помощью интерактивного теста.

**Ссылка на проект:** [gubaisheka.github.io/social-media-safety](https://gubaisheka.github.io/social-media-safety/)

---

## Руководство пользователя

### Структура и навигация

Веб-ресурс включает 11 разделов, доступных через панель навигации в верхней части экрана:

| Раздел | Описание раздела |
|---|---|
| Главная | Обзорная страница веб-ресурса с блоками быстрой навигации. |
| Введение в ИБ | Теоретический фундамент: базовые принципы информационной безопасности и разбор основных угроз. |
| Гид по сайту | Инструкция по навигации и взаимодействию с интерактивными элементами веб-ресурса. |
| Facebook, ВКонтакте, Одноклассники | Практические руководства по защите аккаунтов и чек-листы самопроверки. |
| Instagram, Twitter/X | Пошаговые инструкции по настройке приватности, интерактивные слайдеры со скриншотами интерфейсов и чек-листы самопроверки. |
| Тест | Модуль итоговой проверки знаний, состоящий из 20 вопросов по всем разделам. |
| Инфографика | Раздел с удобными карточками по ключевым правилам безопасности в сети. |
| FAQ | Ответы на частые вопросы пользователей. |

### Интерактивные чек-листы безопасности

Разделы, посвящённые социальным сетям, содержат интерактивные чек-листы для пошаговой настройки приватности. Все рекомендации внутри чек-листов разделены по уровням сложности: «Базовый», «Продвинутый» и «Экспертный».

Порядок работы с чек-листами:

1. Перейдите в раздел интересующей социальной сети через панель навигации или с помощью кнопок навигации в разделе «Гид по сайту».
2. Используйте кнопку быстрого перехода в начале страницы, чтобы переместиться к итоговому чек-листу.
3. Отмечайте выполненные шаги по мере настройки приватности своего аккаунта.
4. Текущий прогресс наглядно отображается на шкале выполнения в нижней части чек-листа.
5. Все изменения автоматически записываются в браузерное хранилище `localStorage`, поэтому прогресс сохраняется при перезагрузке страницы или закрытии вкладки.

В разделе Instagram чекбоксы также интегрированы в финальные шаги интерактивных слайдеров. Состояние этих чекбоксов синхронизировано с итоговым чек-листом на странице.

### Слайдеры со скриншотами настроек

Разделы Instagram и Twitter/X содержат пошаговые слайдеры с актуальными скриншотами интерфейсов. Слайдеры позволяют сопоставить текстовые рекомендации с реальными пунктами меню в настройках аккаунтов.

> **Управление просмотром:** Переключение между шагами выполняется кнопками <kbd>Назад</kbd> и <kbd>Вперёд</kbd>, которые автоматически блокируются, если достигнут первый или финальный слайд инструкции. Любой скриншот можно увеличить, кликнув по нему. Закрыть открывшееся модальное окно можно нажатием на кнопку-крестик или кликом по затемнённому фону вне области изображения (оверлею).

### Итоговое тестирование

Раздел теста предназначен для комплексной проверки знаний, полученных в ходе изучения материалов веб-ресурса. Вопросы охватывают как общие правила информационной безопасности (создание надёжных паролей, двухфакторная аутентификация, защита от фишинга и социальной инженерии), так и специфику настройки приватности в конкретных социальных сетях.

#### Порядок прохождения тестирования:

1. Перейдите в раздел **«Тест (20 вопросов)»** через панель навигации. Также перейти к тесту можно с помощью кнопок навигации в разделах «Главная» и «Гид по сайту».
2. Последовательно ответьте на все 20 вопросов. В зависимости от формулировки задания, в тесте встречаются два типа вопросов:
   * *С выбором одного правильного ответа* — используются переключатели-радиокнопки;
   * *С возможностью выбора нескольких вариантов* — такие вопросы снабжены соответствующей пометкой, а ответы отмечаются чекбоксами.
3. Нажмите кнопку <kbd>Завершить тест и проверить ответы</kbd> внизу страницы. Скрипт автоматически подсчитает количество верных ответов и выведет итоговый результат с оценкой уровня вашей цифровой грамотности.

## Руководство разработчика

### Технологический стек

| Категория | Используемые технологии |
|---|---|
| Разметка | HTML5 (семантическая вёрстка) |
| Стилизация | CSS3 (адаптивный дизайн) |
| Логика | Vanilla JavaScript |
| Хранилище данных | `localStorage` |
| Слайдеры | Собственная реализация |
| Шрифты | Системный стек (`Segoe UI`, `Roboto`, `Arial`) |

> Проект разработан без использования сторонних фреймворков и библиотек и не требует настройки сборщиков или пакетных менеджеров.

### Локальный запуск

> Для корректной работы интерактивных элементов и поддержки браузерного хранилища `localStorage` веб-ресурс необходимо запускать через локальный веб-сервер. Прямое открытие файла `index.html` через протокол `file://` не поддерживается из-за политик безопасности современных браузеров.

Для запуска проекта рекомендуется использовать редактор Visual Studio Code и расширение Live Server:

1. Запустите Visual Studio Code.
2. В верхнем меню выберите `File` -> `Open Folder` (Файл -> Открыть папку) и укажите путь к директории проекта.
3. Установите расширение `Live Server` через вкладку `Extensions` (Расширения).
4. В панели проводника VS Code нажмите правой кнопкой мыши на файл `index.html` и выберите пункт `Open with Live Server`. Также можно открыть файл в редакторе и нажать кнопку `Go Live` в правом нижнем углу строки состояния.
5. Проект автоматически откроется в браузере по адресу `http://127.0.0.1:5500`.

```text

```

### Архитектура программной логики

| Модуль | Функциональные обязанности |
|---|---|
| Навигация | Переключение разделов через перебор элементов `a[data-target]`. Динамическое управление классами активности (`active`, `active-link`) и плавная прокрутка страницы к началу с помощью `window.scrollTo`. |
| Чек-листы | Подсчёт общего прогресса и прогресса по категориям с помощью селекторов атрибутов. Визуальное выделение выполненных пунктов через класс `completed` и сохранение состояний в `localStorage`. |
| Тестирование | Динамическая генерация вопросов из массива объектов. Обработка состояний радиокнопок и чекбоксов. Проверка ответов путём сравнения массивов методом `every` и вывод итогового заключения. |
| Слайдеры | Изолированная инициализация каждого слайдера через `forEach`. Пошаговое переключение видимости слайдов с помощью класса `active` и блокировка кнопок навигации через свойство `disabled`. |
| Модальные окна | Просмотр увеличенных изображений (Lightbox): подмена атрибута `src` по клику на миниатюру, управление отображением оверлея и закрытие окна по клику на крестик или фон. |
